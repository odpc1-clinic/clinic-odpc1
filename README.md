# ระบบเวชระเบียน ศูนย์บริการเวชศาสตร์ป้องกัน สคร.1 เชียงใหม่ (Clinic 2.0)

ระบบเวชระเบียนอิเล็กทรอนิกส์ที่ใช้งานจริงในศูนย์บริการเวชศาสตร์ป้องกัน
สำนักงานป้องกันควบคุมโรคที่ 1 เชียงใหม่ ตั้งแต่ 30 พฤษภาคม 2565
รองรับ 3 คลินิกในฐานข้อมูลเดียว: **STI** (โรคติดต่อทางเพศสัมพันธ์) · **TB** (วัณโรค) · **TMC** (เวชศาสตร์การเดินทาง)

> ชุดโค้ดนี้จัดทำเพื่อให้กรมควบคุมโรคตรวจสอบ (ข้อมูล ณ 12 พฤศจิกายน 2569)
> **ไม่มีข้อมูลผู้ป่วยในชุดนี้** — ตัดสำเนาฐานข้อมูล ไฟล์แนบ และค่าตั้งระบบ (.env) ออกทั้งหมด
> ตัวอย่างเลข HN / เลขบัตรในหมายเหตุโค้ดเป็นค่าสมมติ

## เทคโนโลยี

| ส่วน | ที่ใช้ |
|---|---|
| ภาษา / เฟรมเวิร์ก | PHP 8.4 · Laravel 13 |
| ฐานข้อมูล | MariaDB 11.4 |
| เว็บเซิร์ฟเวอร์ | nginx (CloudPanel) บน Ubuntu 24.04 · server ของสำนักงาน (วงแลนภายใน) |

| แจ้งเตือนนัดหมาย | LINE Messaging API (ส่งออก) · รับข้อความผ่านที่พัก Google Apps Script (`docs/line-link-relay.gs`) |

## มาตรการความปลอดภัยในระบบ

- **ต้องเข้าระบบทุกหน้า**ที่มีข้อมูลผู้ป่วย · ปิดการสมัครสมาชิกเองและการรีเซ็ตรหัสทางอีเมล (`Auth::routes(['register' => false, 'reset' => false])`)
- **บทบาทและสิทธิ์** (spatie/laravel-permission): Admin, Doctor, Nurse, Registrar, Lab, Pharmacy
  บัญชีที่ไม่มีบทบาทใช้งานไม่ได้ (`BlockUsersWithoutRole`)
- **นโยบายรหัสผ่าน** ตามหนังสือ สธ 0418.17/719 ลว. 27 ส.ค. 2569 (`app/Rules/StrongPassword.php`):
  อย่างน้อย 12 ตัว มีตัวพิมพ์ใหญ่/เล็ก/ตัวเลข/อักขระพิเศษ ห้ามซ้ำรหัสเดิม ห้ามมีชื่อ/อีเมล ห้ามคำเดาง่าย
  บัญชีที่ยังไม่เปลี่ยนถูกบังคับให้ตั้งใหม่ก่อนใช้งาน (`ForcePasswordChange`) · ผู้ดูแลไม่เห็นรหัสผ่านของผู้ใช้
- **ไฟล์แนบของผู้ป่วย** (ผลตรวจ / รูป) เก็บนอก public และเข้ารหัสด้วย APP_KEY · เปิดได้ผ่านเส้นทางที่ต้องเข้าระบบเท่านั้น
- **บันทึกการใช้งาน** — ใครแก้อะไรเมื่อไหร่ · เข้า/ออกระบบ (security log) · ไม่บันทึกตัวรหัสผ่านไม่ว่ากรณีใด
- **ผลตรวจ HIV** ปิดไว้ ต้องกดดูทีละรายการ และบันทึกว่าใครดู
- **Security headers** (`SecurityHeaders`) · CSRF ทุกฟอร์ม · `APP_DEBUG=false` บนระบบจริง
- **ตรวจช่องโหว่ไลบรารีอัตโนมัติ**ทุกวันจันทร์ (`php artisan clinic:security-audit` → composer audit) · ผลล่าสุด 2 พ.ย. 2569: 0 รายการ
- **ความยินยอม PDPA** แบบไม่ใช้กระดาษ (`resources/privacy_notice.php`)

## ข้อควรทราบสำหรับผู้ตรวจ

- `database/seeders/RbacSeeder.php` สร้างบัญชีตัวอย่างรหัส `password` — **ใช้กับเครื่องพัฒนาเท่านั้น**
  ระบบจริงไม่ได้ใช้บัญชีเหล่านี้ และบัญชีตั้งต้น `admin@admin.com` บนระบบจริงถูกล็อกแล้ว (รหัสสุ่ม ไม่มีบทบาท)
- ค่าตั้งระบบอยู่ในไฟล์ `.env` ซึ่งไม่อยู่ในชุดนี้ ดูรายชื่อค่าได้ที่ `.env.example`
- ที่อยู่เครือข่ายภายใน (IP server, เครื่องผู้ดูแล, PACS, วงแลน) ในเอกสารและโค้ดแทนด้วยตัวยึดตำแหน่ง เช่น `<SERVER_IP>` · ใบรับรองของเครื่องเดิม (`public/cert/clinic.crt`) ไม่อยู่ในชุดนี้
- หมายเหตุในโค้ดเขียนเป็นภาษาไทย อธิบาย "ทำไม" ของแต่ละการตัดสินใจ และวันที่ที่แก้

## ติดตั้ง (เครื่องทดสอบ)

```bash
composer install
cp .env.example .env && php artisan key:generate   # แล้วตั้งค่า DB_* ใน .env
php artisan migrate
php artisan clinic:smoke-test   # เปิดทุกหน้าหลัก ต้องผ่านทั้งหมด
```

ติดตั้งบน server Linux ดู `docs/deploy-linux.md`
